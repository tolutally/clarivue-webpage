# Clarivue Webpage

This is the official webpage for Clarivue, a structured interview software.

## Development

To run the website locally, you can use any simple HTTP server.

### Using Python

If you have Python installed, you can run the following command from the root of the project:

```bash
python3 -m http.server 8000
```

### Using Node.js http-server

If you have Node.js and `http-server` installed, you can run:

```bash
http-server . -p 8000
```

The website will be available at `http://localhost:8000`.
